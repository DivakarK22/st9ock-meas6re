Connect Zerodha Kite

  1. Create a Kite Connect app at developers.kite.trade.
  2. Export KITE_API_KEY, KITE_API_SECRET, and optionally KITE_ACCESS_TOKEN.
  3. Open the login URL from GET /api/kite/login-url, then post the request_token to /api/kite/session.

Without Kite, the app uses Yahoo Finance, then demo candles if live data is blocked.

Daily email (no website): copy .env.example to .env, add a Gmail app password, then npm run email:preview and npm run email:install-cron for 08:15 IST weekdays.
